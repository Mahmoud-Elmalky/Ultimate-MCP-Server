# Phase Execution Prompt Template

You are implementing one phase of Ultimate MCP Server v2.

1. Read `AGENTS.md`, `PROJECT_BRIEF.md`, `IMPLEMENTATION_ROADMAP.md`, this phase file, and all referenced docs.
2. Inspect current code before editing. Preserve uncommitted user work.
3. Convert every phase requirement into a checklist and map it to files/tests.
4. Implement only this phase's scope; do not add speculative features.
5. Apply the security and reliability requirements in all changes.
6. Add tests before or with each feature; use deterministic mocks by default.
7. Run relevant checks and capture actual commands/results.
8. Update documentation, config examples, dependency locks, and tool catalog.
9. Produce a report using `PHASE_REPORT_TEMPLATE.md`.
10. Do not mark incomplete/unverified items done. Do not advance to the next phase if a critical gate fails.

Use existing repo conventions if they are safe and consistent. If a decision is missing, choose the simplest reversible option and record it in an ADR. Ask the user only for a genuinely blocking decision or required human approval.
